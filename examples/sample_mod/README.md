# Example RMF Mod

This is a demonstration of how an RMF mod should be structured.

## Structure
- `manifest.json`: Contains the mod metadata.
- `icon.png`: A placeholder icon.
- `thumbnail.png`: A placeholder thumbnail.
- `content/`: Where the mod assets reside (e.g., `.rbxm` files).

## Usage
Simply zip the contents of this folder and rename the extension to `.rmf`.
